# Campus Lost and Found Asset Recovery Portal

Help students, teachers, and school staff report lost items, find possible matches, and recover campus belongings.

## Setup

See [SETUP.md](SETUP.md) for database configuration, administrator creation, migrations, and local development instructions.

Install PHP dependencies with `composer install`, then serve the project from its root directory.

## Features

- Lost and found reports
- Smart matching with similarity scores
- Recovery status history
- Location-based campus insights
- Registered asset QR labels
- One-time handover codes for approved pickups
