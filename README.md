

# 🎓 Campus Lost and Found Asset Recovery Portal

**A centralized campus asset recovery system designed to help students, teachers, and school personnel report lost belongings, discover potential matches, and securely recover misplaced items within the campus.**

The **Campus Lost and Found Asset Recovery Portal** provides a digital platform that simplifies the lost-and-found process through intelligent item matching, recovery tracking, location-based insights, and secure handover verification.

Instead of relying on manual announcements or unorganized reports, the system brings lost and found records into one accessible platform, making campus item recovery more organized, efficient, and reliable.

---

## ✨ Key Features

### 🔎 Lost and Found Management

- Submit reports for lost and found belongings.
- Browse and manage reported items.
- Access organized records of reported campus belongings.

### 🧠 Smart Item Matching

- Automatically identify potential matches between lost and found reports.
- Generate similarity scores to help determine how closely reported items match.
- Make the item recovery process faster and more convenient.

### 📋 Recovery Status Tracking

- Monitor the recovery progress of reported belongings.
- Maintain a history of status updates and recovery activities.
- Keep track of item recovery from reporting to successful handover.

### 📍 Location-Based Campus Insights

- Organize lost and found information based on campus locations.
- Provide insights into areas where belongings are frequently reported missing or found.
- Help identify campus locations associated with lost and found activities.

### 🏷️ Registered Asset QR Labels

- Generate QR labels for registered campus assets.
- Make asset identification and information access more convenient.
- Support organized campus asset management.

### 🔐 Secure Item Handover

- Generate one-time handover codes for approved item pickups.
- Add an additional verification step during the recovery process.
- Help ensure belongings are released through an approved handover procedure.

## ⚙️ Installation and Setup

Follow these steps to configure and run the project locally.

### 1. Clone the Repository

```
git clone https://github.com/Jhase3721/Campus-Lost-and-Found-Asset-Recovery-Portal.git
```

### 2. Navigate to the Project Directory

```
cd Campus-Lost-and-Found-Asset-Recovery-Portal
```

### 3. Install Dependencies

Make sure PHP and Composer are installed on your machine.

```
composer install
```

### 4. Configure the Database

Refer to the **SETUP.md** documentation for detailed instructions on:

- Database configuration
- Administrator account creation
- Database migrations
- Local development environment setup

### 5. Run the Project

Once the dependencies and database are configured, serve the application from its root directory using your preferred local PHP development environment.

## 🎯 Project Objective

The primary objective of this project is to modernize the traditional campus lost-and-found process by introducing a centralized and technology-driven asset recovery platform.

By combining smart matching, recovery history, QR-based asset identification, location insights, and secure handover verification, the system aims to improve how campus communities report, locate, manage, and recover misplaced belongings.

---

## 👥 Intended Users

- **Students** — Report lost belongings and search for potentially recovered items.
- **Teachers** — Report, locate, and recover misplaced personal or classroom belongings.
- **School Staff** — Assist in managing reported items and coordinating their return.
- **Administrators** — Oversee records, monitor recovery activities, and manage the platform.
